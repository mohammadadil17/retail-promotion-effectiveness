# Raw data (not included)

This folder holds the untouched Rossmann files, which are not re-hosted here.

1. Download `train.csv` and `store.csv` from the Kaggle competition [Rossmann Store Sales](https://www.kaggle.com/c/rossmann-store-sales/data) (a free Kaggle account is needed).
2. Put both files in this folder.
3. Run the notebooks in order, as described in the main README.

Never edit these files; the cleaning notebook only reads them.
