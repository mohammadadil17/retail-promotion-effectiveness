# Decision deck outline (5 slides)

Audience: retail chain leadership. One message per slide; the title states the finding. Charts are in `docs/figures/`; numbers come from `decision_memo.md`.

## 1. Keep promotions, redesign one segment
- **Title:** "Promotions lift sales by about 38%: keep them, fix type b, get cost data"
- Three-line answer: keep (types a, c, d), redesign and test (type b), stop targeting by competitor distance.
- Big number: **+38%** Mon-Fri sales on promo days; **50 of 50** stores gain.

## 2. The evidence: promotions work everywhere
- **Title:** "Every one of the 50 stores sells more on promo days"
- Chart: `figures/01_promo_vs_no_promo.png`.
- Talking points: like-for-like weekdays only; three methods agree (+35% / +38% / +39%); the lift is more customers (+19%) and higher spend (+15%).

## 3. Where it works, where it does not
- **Title:** "Type b gains least; competitor distance makes no difference"
- Charts: `figures/02_uplift_by_store_type.png`, `figures/03_uplift_by_competition.png`.
- Talking points: type b about +20% vs 35-38% elsewhere, but only 4 sample stores (17 in the chain); nearby competitors do not change the lift.

## 4. What it is worth and what to do
- **Title:** "About EUR 330M a year of extra revenue, almost all from types a, c and d"
- Table: the decision-by-segment table from the memo (uplift, extra sales per promo day, break-even cost).
- Talking points: revenue, not profit; break-even cost at an assumed margin; type b is about 1% of the value, so test cheaply (up to about EUR 1.9M a year upside).

## 5. Risks and next steps
- **Title:** "Confirm cause and profit before scaling"
- Left: top risks (not randomised, no cost data, small sample, one summer window).
- Right: next steps (get cost and margin; controlled test; run on all 1,115 stores and a full year; keep the dashboard).
- Optional appendix: forecast vs actual (`figures/04_forecast_vs_actual.png`) with the honest note that the model is comparable to, not better than, a simple average and runs about 6% low.
